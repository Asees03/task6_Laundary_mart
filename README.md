# task6_Laundary_mart
LaundryCare

LaundryCare is a simple, modern landing page for a laundry service business offering convenient doorstep laundry services.

 Features

* Simple and clean user interface
* Navigation bar with Home, About Us, Services, and Contact links
* Hero section with service description and booking button
* Service highlights: Quality Cleaning, Fast Delivery, and Affordable Prices
* Footer with copyright information

Technologies Used

* HTML5
* CSS3

 How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or use Live Server.
